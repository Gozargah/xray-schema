Required for `https://`. It is a [TLSObject](https://xtls.github.io/en/config/transports/tls.html#tlsobject): the Client Hello is Chrome's unless `fingerprint` says otherwise, and `serverName` can differ from the URL's host, which stays the HTTP Host, e.g. for domain fronting. With `alpn` set to `["h3"]` alone, DoH uses HTTP/3, set by `quicConfig`, a [quicParams](https://xtls.github.io/en/config/transports/finalmask.html#quicparams) that mimics Chrome by default; otherwise HTTP/2 over TLS.
